# N17 — The Signal

A fictional browser-based puzzle hunt inspired by the **mood** of classic internet mystery games.

## Features

- 7 chained sequences from easy to near-impossible
- Caesar, Morse, Base64, Vigenere, hexadecimal and meta-puzzle steps
- Built-in terminal helper
- Hints and reveal system
- English + Persian UI
- Local progress via `localStorage`
- No external network requests
- Designed for GitHub Pages

## Run

Open `index.html` locally or publish the repository with GitHub Pages.

## Safety

N17 is a fictional game. It does not request credentials, contact external servers, or target real systems.

## Structure

- `index.html` — app shell
- `style.css` — visual system
- `game.js` — puzzle engine, terminal, scoring and localization
